# 真戦 編成ノート

「信長の野望 真戦」の手持ち武将・戦法を登録して、Claude に部隊編成を頼むためのプロンプトを作るツールです。
スマホのホーム画面に追加すると、アプリのように使えます（PWA）。

**このリポジトリにはゲームデータは含まれていません。** データは [FORMAT.md](FORMAT.md) の書式で各自用意してください。

## できること

- **ホーム**: 手持ちの所持状況、手持ちで組める推奨編成・あと1人で組める推奨編成、育成メモ
- **武将／戦法**: 一覧・検索・絞り込み、所持と凸数の登録
- **依頼**: 条件（部隊数・目的・COST上限・必須武将など）を入れて、Claude 向けの編成依頼プロンプトを作成。コピーまたは共有
  - 「SKILLあり」: 下の SKILL を入れた Claude 向けの短いプロンプト
  - 「SKILLなし」: 手持ちの効果文を埋め込んだプロンプト（どの Claude にも貼れる）
- **設定**: データの読み込み（書式チェック付き）、手持ちの JSON 書き出し・読み込み

データと手持ちは端末の中（ブラウザの保存領域）にだけ保存され、どこにも送信されません。

## 使い方

1. ツールを開く（GitHub Pages で公開している URL の `/tool/`）
2. 設定 →「サンプルで試す」で動きを確認する
3. [FORMAT.md](FORMAT.md) の書式で `generals.md`・`tactics.md`・`traits.md` を用意し、設定 →「md ファイルを選択」で読み込む
4. 武将・戦法タブで手持ちを登録し、依頼タブでプロンプトを作る

## フォルダ

| パス | 中身 |
|---|---|
| `tool/` | ツール本体（HTML + JS、サーバー不要の静的ファイル） |
| `skill/shinsen-formation/SKILL.md` | Claude 用 SKILL（データと一緒に zip にしてアップロード） |
| `templates/` | 架空の武将・戦法・特性・兵学で書いたサンプルデータ |
| `FORMAT.md` | データの書式 |
